# Project instructions

## UI work

- Before creating or changing any interface in this repository, read `ui-rule.md` and apply it to the affected screens and components. This is an explicit, ongoing user requirement.
- Use the shared design tokens. The current brand colors are the section 0 values: sky blue `#0284C7` and pressed blue `#0369A1`. Later green brand examples in the file are stale; green `#22C55E` remains the semantic success color.
- Follow the file for typography, icon library, safe areas, cards, bottom sheets, 44px minimum touch targets, text overflow, spacing, and loading/error/empty states.
- Preserve the existing feature navigation and real data flows while applying the visual rules. Do not invent completion percentages or activity counts when the API does not provide them.
- Before handoff, run TypeScript and lint for the changed files, and state any device-preview limitations honestly.
